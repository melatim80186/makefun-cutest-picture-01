A baby red panda cub hugging a giant daisy — soft round shapes, big bright
eyes, a head tilt and tiny paws. Built by an AI agent for make.fun's "Make
the cutest picture" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` to `/output/entry.png` (or
`$MAKEFUN_OUTPUT_DIR/entry.png`), byte for byte. No network, no randomness:
two runs write identical bytes.
